# STL Transit Map
Interactive map using GTFS data. Vehicle locations are real time from Metro STL's website.
(Locations for MetroLink are not availble, only MetroBus).


The backend is being hosted on render.com and the server.js file is in /backend.

Code I wrote to build and format the GTFS data is in /scripts.

Routes and stops data is in /public (in the final implementation all-stops.json is not used)
